# Chello's Little World ♡ — 19th Birthday Scrapbook

> *A bespoke, responsive, and romantic digital scrapbook website celebrating Bhavasri's 19th Birthday.*

🌐 **Live Website**: [https://shashtika-bot.github.io/chellos-little-world/](https://shashtika-bot.github.io/chellos-little-world/)

---

## ✨ Features

- **Envelope Introduction**: Blush pink opening screen with interactive wax seal envelope and full keepsake letter modal.
- **Sticky Scrapbook Navigation**: Smooth-scrolling links with responsive mobile drawer.
- **Birthday Hero & Music Player**: Romantic editorial typography, overlapping tilted Polaroids, and built-in acoustic music-box synthesizer.
- **Nineteen Section**: Enormous serif display, floating confetti particles, and heartfelt prose.
- **Personality Collage**: 8 custom handwritten stickers with tilted polaroids.
- **Snapshots Archive**: 10 Polaroid memories with an expanded dark-chocolate modal, date tags, and prev/next controls.
- **The Little Things & Gratitude Grid**: 18 heartfelt paper notes with realistic washi tape and drop shadows.
- **3D Flip Cards**: 10 interactive cards that flip to reveal personality traits and reasons to cherish.
- **A Little Bit Of Our Chaos**: 11 interactive memory chapters updating dynamic notes and polaroids.
- **Some People Become Memories**: Deep chocolate centerpiece with opposite polaroids and emotional tribute.
- **Our Little Universe**: Dark celestial constellation map with clickable glowing star coordinates.
- **Birthday Finale**: Grand celebration with celebratory confetti burst, cake wish interaction, and sign-off.

---

## 🛠️ Technology Stack

- **React 18**
- **Vite 6**
- **Lucide Icons**
- **Canvas Confetti**
- **Web Audio API** (Procedural romantic music-box synth)
- **GitHub Actions & GitHub Pages** for automated deployment

---

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/Shashtika-bot/chellos-little-world.git

# Navigate into project directory
cd chellos-little-world

# Install dependencies
npm install

# Start development server
npm run dev
```

---

## 📝 Customizing Memories & Photos

Edit `src/data/scrapbookData.js` to replace any placeholder photos or audio tracks with your own!
